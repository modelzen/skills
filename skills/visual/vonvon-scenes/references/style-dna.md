# 风格 DNA

## 核心公式

```text
一个真实主物件 / 一个 Vonvon 核心动作 / 2-4 个短标签 / 少量彩色点缀 / 足够留白
```

## 标准 16:9

- 纯白 `#FFFFFF` 无缝背景与白色摄影棚表面。
- 场景通常覆盖画面宽 55%-70%、高 34%-48%；中等偏轻，不 close-up，不 miniature。
- 一个真实主物件或紧凑物件组，最多 1-2 个小配件。
- 统一透视、软接触阴影和材质；无矩形贴图边界、UI 或 Logo。
- 只有一个核心冲突，2-4 个短标签，优先 3 个。
- Vonvon 通常占画面高度 12%-20%，上限 24%；物件和冲突承担视觉重心。

## 彩蛋长卷

- 2.6:1-3:1 超横版，高级近白 `#FAFAF8` / `#FBFBFA` 空气感。
- 一条细黑手绘路线横贯全图，节奏自然、不规律。
- 5-8 个不等距节点，避免平直横排、规则正弦波和高低机械交替。
- 左侧身份/起点，右侧当前关注/结论。
- 每个节点一个真实物件和同一个 Vonvon 的动作状态；文字直接写在空白中。
- 单个 Vonvon 通常占画面高度 7%-11%，不得大过节点主物件；节点必须有明显、不规律的高低与大小节奏。
- 无序号、编号圆点、时间轴模块和便签卡片阵列。

## 色彩

- Vonvon 固定使用黑/白/品牌橙。
- 蓝、粉、黄、绿、红只做胶带、圆点、下划线和警告节奏。
- 每张标准图约 4-6 个小点缀；长卷跟随节点节奏，不平均撒满。

## 禁止

- PPT、流程图、课程页、商业海报、科技 UI、办公室或夜景背景。
- 普通猫咪照片、3D 玩具、毛绒角色、儿童卡通。
- 暖白、灰白、暗角、纸纹、重渐变、拼贴边界。
- 物件清单化、多个不相关现场、大段解释文字。
- 角色过大、正面摆拍、长前臂、过肩举物、人类肩肘动作，或长卷退化成等距大猫陈列。
