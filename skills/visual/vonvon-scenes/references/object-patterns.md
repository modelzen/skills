# 真实物件模式

## 标准结构

- **拉扯**：会议、需求、下班失败。Vonvon 被挂绳、胶带或纸条拉向真实入口。
- **涌出**：消息、任务、Bug、素材。Vonvon 挡、接、推回或整理从出口冒出的东西。
- **打结/回流**：报警、返工、问题回归。Vonvon 集中处理路径上的结或卡点。
- **审查**：Review、验收、复核。Vonvon 在检查工具下修、查、圈、盖。
- **重命名**：AI 替代、岗位变化、定位变化。Vonvon 拉住、撕开或重新贴标签。
- **筛选**：简历、关键词、机会过滤。Vonvon 推入、接住、救回或守住入口。

同一动作可以更换物件。不要总用手机、电脑、放大镜、工牌或筛子。

## 长卷结构

左起点 + 不规律曲线路径 + 5-8 个实物节点 + 同一 Vonvon 连续参与 + 右收束。它是故事线，不是信息图时间轴。

## 原创三步

1. 写冲突句：读者被 X 以 Y 推向 Z。
2. 把 X/Y/Z 换成一个真实物件和一个动作。
3. 让 Vonvon 直接抓、推、挡、扛、解、改、撕或接。

物件必须熟悉、可互动、不依赖 UI 截图。若主物件和母版相同，空间关系和 Vonvon 动作必须显著不同。
