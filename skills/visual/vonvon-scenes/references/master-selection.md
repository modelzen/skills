# 母版选择与拦截

## 标准母版

- `01-meeting-pull-in.png`：会议、同步、对齐、临时拉回。抽象骨架是多方拉力把角色拖向工作入口。
- `02-message-overload.png`：消息、任务、催促。骨架是一个出口涌出太多东西，角色正在挡或接。
- `03-production-alert.png`：报警、返工、打结、回流。骨架是路径卡在一个结上，角色集中处理卡点。
- `04-review-rework.png`：审查、校对、验收、兜底。骨架是检查工具压住/放大局部，角色亲自修改。
- `05-automation-relabel.png`：自动化、岗位重组、身份变化。骨架是真实标签重新定义角色，角色发生拉扯。
- `06-keyword-filter.png`：筛选、过滤、机会流失。骨架是入口/出口制造过滤，角色接触被筛物。

## 长卷母版

- `07-long-scroll-story-master.png`：个人经历、项目复盘、产品演化、成长路径。锁定超横版、近白背景、有机曲线、不等距真实物件节点、同一 Vonvon 逐段参与、左起右收；不锁定具体经历、文字或物件。

## 必填锁定

```text
母版：
抽取的不变量：
当前内容的变异点（标准模式至少 3 个）：
画面 3 秒读懂句：
当前内容适配：
要避免的失败信号：
```

若出现元素清单化、母版换皮、物件拼贴、角色悬浮或三秒读不懂，候选直接拦截。

## 角色姿势拦截

- `01` 拉扯必须用坐地、伏身或四足低位支撑，双爪抓同一受力点；不用长手臂或人类后仰拔河。
- `02` 挡消息必须用双爪共同压住/推住挡板，身体有地面支撑；不用单臂站立摆拍。
- `04` 修改必须让两只短爪靠近纸面或工具；不用一条长臂跨过身体够放大镜。
- `07` 每个节点由真实物件承载阶段记忆，角色小于物件且姿势各异；禁止六只等大猫沿水平线陈列。
- 母版若出现以上失败姿势，只保留抽象冲突与物件关系，不把角色姿态传给新图。
