# Vonvon 实物场景图

> 来源：本 Skill 基于 Ian 的 [Ian Xiaohei Scenes](https://github.com/helloianneo/ian-xiaohei-scenes) 修改而来，详见 [`NOTICE.md`](./NOTICE.md)。

## 核心定位

把文章观点、真实处境、项目过程和成长故事转译成：

```text
Vonvon + 一个真实物件现场 + 一个物理动作 + 短中文标签 + 留白叙事
```

Vonvon 是白色梨形、黑粗轮廓、纯黑圆眼、橙脸颊与斑块、戴连体小猫装饰宽檐帽的平面手绘小猫。它作为二维手绘角色嵌入真实摄影物件现场，不能变成真猫、3D 公仔或普通萌宠。

视觉层级必须是“真实物件与物理冲突第一，Vonvon 身份第二”。角色负责让冲突发生，不负责占据画面成为吉祥物海报。

两种模式：

- **标准模式**：16:9、纯白 `#FFFFFF` 摄影棚、一个真实物件小现场。
- **彩蛋长卷**：约 2.6:1-3:1、高级近白背景、一条曲线路径、5-8 个真实物件节点。

若用户要求白板手绘解释图、流程或方法论，优先使用 `$vonvon-illustrations`；若要求真实物件、共鸣现场、生活质感或长卷故事，使用本 Skill。

## 工作流

### 1. 找处境和冲突

先写清：谁，被什么，以什么方式，推向什么结果。再把抽象词换成拉、拽、压、筛、盖、卡、打结、贴标签、挡、托、剪、缝等可见动作。

选择一个读者熟悉、可与 Vonvon 发生物理接触的真实主物件。标准图最多再加 1-2 个小配件和 2-4 个短标签。

长卷先拆成 5-8 个事实锚定节点：左侧起点、中段转折、右侧现在/结论。人物经历、品牌、数字、公司或项目事实只能来自用户输入或用户素材。

### 2. shot list 或直接生成

用户只说分析时，标准模式默认输出 4-8 张 shot list；每张写母版、共鸣点、核心冲突、真实物件、Vonvon 动作、受力与支撑方式、角色尺寸预算、短标签、三秒读懂句和至少三个变异点。

用户明确要求生成时，直接逐张出图，但内部先完成母版锁定。长卷默认先生成一张完整母版效果图。

### 3. 母版锁定

标准模式从 `01-06` 选母版，长卷必须锁定 `07`。写：

```text
母版：
抽取的不变量：
当前内容的变异点（标准模式至少 3 个）：
画面 3 秒读懂句：
当前内容适配：
要避免的失败信号：
```

母版只提供比例、留白、物件真实感、动作类型和标签密度，不提供可描摹的布局。

### 4. 单张生成

每张独立调用内置图像生成工具，并把 `assets/vonvon-character-reference.png` 作为身份参考输入。

标准模式必须锁定：

- 16:9、无缝 `#FFFFFF` 背景、统一白色摄影棚表面。
- 一个真实主物件或紧凑物件组、一个核心物理动作、最多 1-2 个小配件。
- Vonvon 保持平面贴纸手绘质感，并与物件共享接触关系和轻微落地阴影；不得毛绒化、3D 化。
- 标准图中 Vonvon 通常占画面高度 12%-20%，上限 24%；真实主物件不应比角色更小或更弱。长卷单个 Vonvon 通常占画面高度 7%-11%，各节点大小随远近轻微变化。
- Vonvon 可双脚站立，但必须短腿、低重心、尾巴与两只前爪完整。高受力动作优先坐地、腹部贴近地面的低位伏身、四足趴姿或双爪并排抓推；禁止长前臂、过肩举物、双手欢呼、扎马步、跪姿、长腿跨步、像人走路或缺爪。
- 2-4 个短中文手写标签，少量蓝/粉/黄/绿/红节奏点；角色橙色斑块必须稳定。

长卷必须锁定：

- 2.6:1-3:1 高级近白长卷、一条有不规律起伏的细黑手绘路线。
- 5-8 个不等距真实物件节点；每个节点有同一个 Vonvon 的连续动作状态。
- 真实物件承载阶段记忆，Vonvon 必须小于或不大于该节点主物件；节点不能退化成六只大猫的水平角色展示。
- 左起右收，不编号、不做卡片模块、不做规律正弦波。
- 节点文字自由落在空白处，不塞进便利贴框。

### 5. 候选 QA

第一张只算候选。用图像查看工具逐张对照角色参考和母版，并放大检查两只前爪、短后腿、尾巴、抓握遮挡、支撑面和受力方向；同时检查角色是否抢过真实物件。任一 CRITICAL 失败就重生成或局部修复。

### 6. 保存交付

标准模式保存到：

```text
assets/<topic-slug>-vonvon-scenes/
```

长卷保存到：

```text
assets/<topic-slug>-vonvon-long-scroll/
```

有序命名，不覆盖旧资产。交付时展示图、说明用途与路径，并标出仍有文字稳定性问题的候选。

## 完成门禁

- `DONE`：通过角色、物件、动作、母版、文字、事实和原创性门禁。
- `DONE_WITH_CONCERNS`：只有轻微标签或光影问题，已清楚说明。
- `BLOCKED`：没有主题/节点，或缺少角色参考图。

若 Vonvon 与真实物件没有明确物理接触，或删掉角色后现场仍完整成立，不得交付。
若第一眼只看到大猫而不是现场冲突，也不得交付。
