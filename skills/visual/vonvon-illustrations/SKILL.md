# Vonvon 手绘正文配图

> 来源：本 Skill 基于 Ian 的 [Ian Xiaohei Illustrations](https://github.com/helloianneo/ian-xiaohei-illustrations) 修改而来，详见 [`NOTICE.md`](./NOTICE.md)。

## 核心定位

把中文内容里的一个关键判断、流程、结构、状态或隐喻，变成一张清爽、怪诞、可读但不像说明书的手绘解释图。

固定主角是 Vonvon：白色梨形小猫、粗黑轮廓、纯黑圆眼、橙色脸颊与斑块，戴着有连体小猫装饰的宽檐帽。Vonvon 必须亲自承担核心动作，不能只是站在角落里卖萌。

视觉层级必须是“隐喻与动作第一，Vonvon 身份第二”。角色可以可爱，但构图不能以展示吉祥物为目的；先看懂它正在修、推、接、拉什么，再认出这是 Vonvon。

这套图不是商业插画、PPT 信息图、儿童绘本或普通猫咪海报。

## 按需读取

- `references/style-dna.md`：画面比例、颜色、文字和禁忌。
- `references/vonvon-ip.md`：Vonvon 的身份不变量、动作弹性和失败信号。每次生图前必读。
- `references/composition-patterns.md`：结构类型、原创隐喻和反复刻规则。
- `references/master-selection.md`：八张母版的适用场景与锁定格式。生成前必读。
- `references/prompt-template.md`：单张生成与局部编辑模板。
- `references/qa-checklist.md`：候选图检查与迭代规则。
- `assets/vonvon-character-reference.png`：角色身份基准。每次生成或修复角色时作为参考图输入。
- `assets/examples/`：八张重新生成的 Vonvon 质量母版。只抽取风格和结构不变量，不描摹布局。

## 工作流

### 1. 提炼认知锚点

读完用户内容后，先回答：

- 核心观点是什么？
- 哪一处承担认知转折？
- 哪个抽象概念能变成明确的物理动作？
- 哪些段落不需要图？

不要平均配图。优先画断点、闭环、分流、前后对比、承接、角色状态、系统负担、证据累积等认知锚点。

### 2. 输出 shot list 或直接生成

用户只要求分析时，默认给 4-8 张 shot list；每张写：放置位置、母版、核心意思、结构类型、物理隐喻、Vonvon 动作、受力与支撑方式、角色尺寸预算、短标签、至少三个变异点。

用户明确要求“生成 / 输出 / 做图 / 看效果”时，不停在方案，直接逐张生成，但内部仍要先完成母版锁定。

### 3. 母版锁定

从 `assets/examples/` 中编号为 `01` 至 `08` 的母版选择最接近的一张质量锚点。生成前写清：

```text
母版：
抽取的不变量：
当前内容的变异点（至少 3 个）：
画面 3 秒读懂句：
要避免的失败信号：
```

母版不是可复制构图。主物件、空间方向、Vonvon 动作、配件组合、标签位置、视角或叙事重心至少三项不同。

### 4. 单张生成

每张单独调用内置图像生成工具，不做拼图。必须把 `assets/vonvon-character-reference.png` 作为角色参考输入，并在提示词中锁定：

- 16:9 横版、纯白背景、黑色略抖手绘线稿。
- Vonvon 白身不填黑；粗黑轮廓、纯黑圆眼、橙色脸颊/耳内/斑块。
- 宽檐帽和帽顶连体小猫装饰始终与主角连接。
- 品牌橙用于主路径与角色斑块；红色只点重点；蓝色只补充状态。
- 一个核心动作、一个主隐喻、3-6 个短标签、大量留白。
- 普通单角色画面里，Vonvon 通常占画面高度约 18%-28%，不超过 32%；只有“角色状态/分镜”才能重复同一个较小角色。主物件或结构必须比角色更有叙事权重。
- 角色外轮廓可以略粗，环境、箭头、批注与物件必须使用更细、更轻的手绘线，避免整张图变成粗线吉祥物海报。
- 动作必须符合小猫身体：可双脚站立，但短腿、低重心、圆润，尾巴与两只前爪完整。高受力动作优先坐地支撑、低位伏身、四足趴姿或两只短前爪并排推拉；禁止长前臂、过肩举物、举手欢呼、扎马步、跪姿、长腿跨步、像人走路或缺爪。
- 禁止普通猫、真实毛猫、3D、公仔、第二只猫、吉祥物海报、PPT、复杂背景。

### 5. 查看候选并迭代

第一张永远只是候选。用图像查看工具逐张检查，并与所选母版、角色参考一起比较。放大检查两只前爪、两只短后腿、尾巴、接触点和受力方向。角色身份错误、动作不清、手臂像人、角色过大、中文错字、画面像 PPT、复刻母版或 3 秒读不懂时，重写提示词并重生成或局部编辑。

### 6. 保存交付

保存到：

```text
assets/<article-slug>-vonvon-illustrations/
```

按 `01-topic-name.png` 顺序命名，不覆盖旧资产。交付时展示图片，说明每张用途、路径和仍需迭代的候选。

## 完成门禁

- `DONE`：shot list 完整，或所有图片通过角色、构图、文字和原创性 QA。
- `DONE_WITH_CONCERNS`：仅有轻微文字稳定性或线条一致性问题，已明确标注。
- `BLOCKED`：缺少要表达的内容，或无法取得 `assets/vonvon-character-reference.png`。

如果删掉 Vonvon 后隐喻仍完全成立，角色就是装饰，不能交付。
如果第一眼只看到“可爱大猫”，第二眼才寻找结构或物件，同样不能交付。
