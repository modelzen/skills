# Vonvon 品牌形象

## 身份基准

生成前查看并作为图像参考输入：

```text
assets/vonvon-character-reference.png
```

只取中央角色，不取原 Logo 的白色外框、圆角边框、水印或背景。

## 硬性识别点

- 白色梨形猫身，头身连成柔和轮廓，坐姿基准稳定。
- 粗而略有手绘抖动的黑色外轮廓。
- 两只纯黑圆眼：无眼白、无高光、无彩色虹膜、无可移动瞳孔。
- 小黑鼻和简洁 `w` 形嘴，三根短胡须。
- 橙色圆脸颊、橙色耳内、橙色尾尖和少量身体斑块。
- 宽檐猫耳帽；帽顶的小猫脸是固定连体装饰，不是第二只宠物。
- 黑、白、橙三色身份优先，不使用渐变和体积高光。

## 手绘模式弹性

- 可以双脚站立、坐、趴、伏身、推、拉、扛、剪、接、搭桥、拧阀门。
- 双脚站立不是拟人错误：正确范例是短短后腿、圆润低重心、身体仍像猫、尾巴清楚、两只前爪完整。`assets/examples/03-chaos-to-order.png` 中转动手柄的 Vonvon 是正向站姿范例。
- 四肢必须完整可解释：两只短后腿 + 两只前爪；遮挡可以隐藏局部，但不能无故少一只前爪。
- 被拉扯时身体可轻微拉长；被压时可轻微压扁；不得改变为黑色豆形角色。
- 表情保持可爱、平静、专注。可爱是身份，不必刻意压成严肃小人；幽默主要来自动作。

## 角色尺度与视觉层级

- 普通单角色正文图里，Vonvon 高度通常约为画面高度的 18%-28%，上限约 32%。
- 角色状态或小漫画可以重复同一个更小的 Vonvon，但不能用多个大头角色平铺占满画面。
- 帽子和脸保证身份，物件和动作负责叙事。不能为了完整展示角色而放大到遮住隐喻。
- 角色外轮廓可以比环境线略粗；物件、箭头、路径和批注必须更细、更轻。

## 猫科动作语法

生成前必须能回答：胸腹如何支撑？两只前爪接触哪里？两只短后腿落在哪里？尾巴如何平衡？力从物件传到哪里？

- 推、拉、挡、扛等高受力动作优先使用：坐地双爪并排、腹部贴近地面的低位伏身、四足趴姿、趴在边缘或踩同一稳定支撑面。
- 前爪是短而圆的猫爪，不画独立的人类肩膀、肘关节或超过身体宽度的长前臂。
- 需要够高物件时，降低物件、让角色趴在边缘或增加小凳；不要把手臂拉长到头顶。
- 双爪共同受力时，两只爪都应清楚可见，并通过抓握、遮挡或压住边缘表现接触。

## 猫科动作规则

- 允许：短腿直立、后腿略分开但不超过身体宽度、坐姿、四足趴伏、前身压低拉扯、双前爪抱/推/拉物件。
- 禁止：人类扎马步、跪地、单膝跪、长腿跨步、直立行走、跑步者式摆臂、骨盆扭转或人类举重姿态。
- 做高处动作时优先坐在小凳、趴在物件边缘、用尾巴平衡，或让两只短后腿落在同一稳定支撑面。
- 动作再夸张，也要能回答：两只前爪在哪里？两只短后腿如何支撑？尾巴如何保持猫的轮廓？

## 直接失败

- 画成普通猫、真猫、长毛猫、橘猫、黑猫、3D 猫或毛绒玩具。
- 身体填成黑色，或把眼睛画成白点眼。
- 去掉帽子、橙脸颊或纯黑圆眼。
- 帽顶小猫脱离，成为第二只独立角色。
- 扎马步、跪姿、长腿走路、像人迈步，或无故少一只前爪。
- 长手臂举过头顶、双手欢呼、单条蛇形前肢、悬空托盘、用人类肩肘发力。
- 增加复杂服装、项圈、徽章、文字 Logo 或用户未要求的道具。
- 角色只站在旁边看，删掉后图意不变。
- 角色比核心物件更大、更醒目，第一眼变成吉祥物海报。

## 动作判断

每张图都用一句动词描述 Vonvon：正在拉、推、扛、塞、捞、压、称、剪、拧、守、接、拆、搭、修。说不出明确动词时，先重写构图。
