# 母版选择

母版是质量锚点，不是描摹模板。

## 索引

- `01-handoff-gaps.png`：断点、承接失败、流程中断。骨架是连续路径出现两个物理缺口。
- `02-minimum-loop.png`：输入、生产、交付、反馈闭环。骨架是一个低科技处理装置和明确回路。
- `03-chaos-to-order.png`：混乱到有序、手动到自动、散乱到收拢。骨架是前后对比和一个转化动作。
- `04-three-working-states.png`：多角色职责、三个内容任务、连续状态。骨架是同一 Vonvon 的三种动作状态。
- `05-information-well.png`：信息噪音、优先级、从大量输入中捞取行动。骨架是深容器与取出动作。
- `06-system-load-bearing.png`：重复劳动、系统负担、人工兜底。骨架是压力转移和承重关系。
- `07-trust-path.png`：陌生到信任、证据累积、转化前的承接。骨架是逐步铺设的路线。
- `08-review-return-loop.png`：审查、返工、修正、再提交。骨架是内容被退回，Vonvon 亲自修补。

## 锁定格式

```text
母版：
抽取的不变量：
当前内容的变异点（至少 3 个）：
画面 3 秒读懂句：
要避免的失败信号：
```

若第一眼像旧母版换字，直接失败。

## 角色姿势拦截

母版只锁动作关系，不锁角色姿势。每次生成还必须检查：

- `01` 的承接应是低位双爪递送/推动，不是头顶举托盘。
- `05` 的打捞应让胸腹有支撑、双爪共同受力，不是水平飞行或拉长双臂。
- `06` 的承重/减负应靠坐地、伏身或双爪操作低位装置，不用单条长臂够高处滑轮。
- 任何母版出现角色过大、正面摆拍、长臂或人类肩肘时，不得作为姿势参考，只保留抽象结构。
